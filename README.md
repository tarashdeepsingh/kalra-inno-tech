# Kalra Inno Tech Pvt Ltd

### Description
-----------------
Kalra Inno Tech Pvt Ltd project powered by Vite with TypeScript, utilizing various UI components and libraries.

### Features
-----------------
1. Vite for fast development builds and optimized production bundles.
2. React with TypeScript for type safety and a smooth development experience.
3. UI components from Radix UI for highly customizable and accessible UI elements.
4. React Query for managing server-side data and caching.
5. Framer Motion for smooth animations.
6. TailwindCSS for utility-first CSS styling.
7. React Hook Form for efficient form handling.
8. Zod for schema validation.

### Technologies Used
-----------------
- TypeScript: ^5.5.3
- Vite: ^5.4.1
- TailwindCSS: ^3.4.11
- Framer Motion: ^12.6.3
- Radix UI: (various components) ^1.1.0 - ^2.2.1
- React Query: ^5.56.2
- React Hook Form: ^7.53.0

### Prerequisites
-----------------
Before you begin, ensure you have the following installed:

- [Node.js](https://nodejs.org/) (v20 or later)
- [npm](https://www.npmjs.com/) (comes with Node.js)

### Installation
-----------------
###### To get started with the project, follow the instructions below:

1. Clone the repository:
```bash
git clone https://github.com/tarashdeepsingh/kalra-inno-tech.git
cd nas-dashboard
```

2. Install dependencies (using npm):
```bash
npm install
```

3. Run the development server (using npm):
The app will be accessible at `http://localhost:3000`
```bash
npm run dev
```

### To build the project for production, run:
------------
1. Build the code
```bash
npm run build
```
